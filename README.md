# パチンコ攻略NAVI Ver.2

## 更新内容
- 既存のトップページ・検索・ボーダー/期待収支計算を維持
- 実在する機種名10件を追加（**スペックは未検証のため未掲載**）
- 記事エディターを追加（ブラウザ内保存 + articles.json 書き出し）
- backup-v1 に受領した旧ファイルを保存

## 公開手順（スマホ）
1. 現行GitHubリポジトリのバックアップを保持する。
2. ZIPを解凍し、**backup-v1以外の** index.html / style.css / app.js / machines.js / articles.js / articles.json をGitHubリポジトリ直下にアップロードする。ZIPのままアップロードしない。
3. mainにコミットするとGitHub Pagesが更新される。
4. 記事を作ったらエディターの「公開用データをダウンロード」で articles.json を取得し、GitHubの同名ファイルを置き換えてコミットする。端末保存のみでは公開されない。

## 重要な注意
- 実在機種の機種名・メーカー名は一次資料と照合前の候補です。正式名称・型式・メーカー・スペックを確認してから公開してください。
- 未検証機種の payout は null で、計算への流用を防いでいます。旧サンプル機種の値はデモ用です。
- 既存の計算式は簡易モデルのままで、実機ボーダーの正確な算出ではありません。
- 公開記事の削除は、記事JSONを書き出して更新する必要があります。
- 端末のデータを消すと未公開記事が消えるため、定期的にJSONを保存してください。
