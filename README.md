# パチンコ攻略NAVI（白×青・スマホ対応）

静的サイトです。HTML / CSS / JavaScript のみで動き、ビルド不要です。

## ファイル
- `index.html`: トップページ・機種詳細・計算ツール
- `style.css`: スマホ対応のデザイン
- `machines.js`: 架空のサンプル機種データ
- `app.js`: 検索・詳細表示・計算ロジック

## スマホだけで公開
1. ZIPを解凍し、**中の4ファイル**をGitHubの新規リポジトリ直下にアップロードします（ZIPのままアップロードしない）。
2. GitHub Pagesならリポジトリの **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save** を選びます。数分後に表示される公開URLを開いてください。
3. 独自ドメインを使う場合はPagesのCustom domain設定を確認してください。

※GitHub Pagesの利用条件を確認してください。特に収益化や商用利用を考える場合はホスティング事業者の規約・広告ポリシーを確認し、必要に応じて商用利用可能なプランを選んでください。

## 機種データの追加
`machines.js` の配列にオブジェクトを追加します。`id` は重複させず、文字列には適切な引用符を使ってください。現在の機種名・スペックはすべて架空です。実機データに置き換えるときはメーカー等の一次資料を照合し、出典と確認日を記録してください。

## 計算の注意
- 簡易ボーダー = 1000 / (1回転あたり期待払い出し玉数 × 交換率)
- 想定回転数 = 投資額 / 1000 × 1000円あたり回転数
- 期待差額 = 想定回転数 × 1回転あたり期待払い出し玉数 × 交換率 − 投資額

実機の厳密な計算ではありません。大当たり分布・払い出しと純増・持ち玉比率・電サポ中の増減・再投資・時間などを考慮していません。投資や遊技の結果を保証しません。
